# BlueRetro + Murmulator — руководство пользователя (Pairing / Unpairing)

**Версия документа:** 1.1 · **Дата:** 2026-10-02

Пошаговая инструкция для повседневного использования: как подключить Bluetooth-геймпад к BlueRetro на Мурмуляторе, как его отключить, как полностью забыть пару (не проверено) и какие геймпады совместимы. Вся техническая часть проекта — распиновка, электрическая схема, прошивка и сборка — вынесена в `blueretro-murmulator-project-summary.md`, здесь описано только пользовательское взаимодействие.

---

## 1. Пейринг Bluetooth-геймпада (проверено, Xbox One)

**Совместимость контроллера:** сопрягаются по Bluetooth только модели Xbox One геймпада с кнопкой **Sync** (чёрная круглая кнопка сверху, рядом с портом USB) — обычно модель **1708** и новее ("controller S"). Более старая модель **1537** работает только по проприетарному Xbox Wireless (без Bluetooth) и с BlueRetro не спарится.

**Режим Inquiry (поиска) — поведение по умолчанию (Auto):** если ни один контроллер не подключён, BlueRetro **автоматически** входит в режим поиска (inquiry) сразу при включении питания — нажимать кнопку BOOT/IO0 для первого пейринга **не требуется**.

Кнопка BOOT/IO0 (удержание 3–6 сек) нужна только в следующих случаях:
- пейринг уже завершился/отключился по таймауту, а нужно включить его заново;
- нужно допарить **второй** контроллер, когда первый уже подключён (у первого порта пейринг после успешного коннекта отключается);
- в BLE Web Config режим Inquiry переключён с **Auto** на **Manual** — тогда автовход в пейринг при старте отключается, и включать его нужно вручную каждый раз той же кнопкой.

**Порядок пейринга (первое подключение, режим Auto — по умолчанию):**

1. **Убедиться, что BlueRetro в режиме поиска:**
   - Включить питание BlueRetro — при отсутствии подключённых контроллеров он сам уйдёт в inquiry mode.
   - В этом состоянии **пульсируют два светодиода**: глобальный LED (IO17) и LED первого свободного порта (порт 1, IO2) — это подтверждение активного поиска. Второй порт (IO4) при этом выключен.
   - Если ни один LED не пульсирует (например, включён Manual-режим или пейринг уже был отменён) — удержать BOOT/IO0 **3–6 секунд**, чтобы включить поиск вручную.
2. **Перевести геймпад Xbox One в режим пейринга:**
   - Включить геймпад кнопкой **Xbox** (в центре).
   - Зажать чёрную кнопку **Sync** и держать, пока логотип Xbox на геймпаде не начнёт мигать.
3. **Завершение сопряжения:**
   - Логотип на геймпаде перестаёт мигать — сопряжение завершено.
   - Глобальный LED (IO17) **гаснет**, а LED занятого порта (порт 1, IO2) переходит из пульсации в **постоянное свечение (solid)** — это и есть индикация успешного подключения к конкретному порту.
4. **Инициализация стика:** нажать кнопку **A** несколько раз — нужно для корректной калибровки центрального значения аналогового стика.
5. **Повторные подключения:** заново пейрить не требуется — короткое нажатие кнопки Xbox на геймпаде переподключает его к BlueRetro автоматически.

**Второй геймпад:** после подключения первого контроллера глобальный LED (IO17) погашен, поэтому для второго геймпада нужно вручную включить поиск (удержание BOOT/IO0 3–6 сек, см. выше) — тогда LED порта 2 (IO4) начнёт пульсировать и по завершении пейринга также перейдёт в постоянное свечение.

**Настройка через Web Config:** после пейринга в BLE Web Config (blueretro.io либо локальный конфиг) убедиться, что output config нужного порта (#1 или #2) выставлен в режим **GamePad** (не Dual/Four Score).

**Соответствие битов DATA ↔ кнопки Xbox One подтверждено осциллографом** — см. раздел «Проверка сигналов осциллографом» в `blueretro-murmulator-project-summary.md` (A→A, X→B, View→Select, Menu→Start, D-pad→Up/Down/Left/Right).

## 2. Отключение / удаление пары (Unpairing)

Два разных сценария — просто отключить геймпад сейчас, или полностью забыть его (удалить ключ сопряжения).

### 2.1. Быстрое отключение (disconnect, без удаления пары)

Короткое нажатие кнопки BOOT/IO0 **вне режима inquiry** — отключает все Bluetooth-устройства от адаптера.

⚠️ Это разрыв текущего соединения, а не удаление ключа сопряжения — геймпад остаётся в памяти BlueRetro и при следующем включении сможет переподключиться автоматически (просто нажатием кнопки Xbox), без повторного пейринга.

**После отключения геймпада** LED освободившегося порта гаснет, а адаптер сам возвращается в режим поиска на этом порту: глобальный LED (IO17) и LED освободившегося порта снова начинают пульсировать одновременно — так же, как при первом включении.

### 2.2. Полное удаление ключей сопряжения (настоящий unpair, не проверено)

Нужно, если геймпад больше не будет использоваться с этим адаптером, или чтобы освободить слот (всего доступно до 16 ключей classic BT и 16 ключей BLE).

**Через кнопку BOOT/IO0** — удержание **6–10 секунд** (LED быстро мигает):
- Сбрасывает конфигурацию к дефолтной **и очищает все сохранённые ключи BT-пейринга**.

**Через Web Config:** на странице **System manager** (https://blueretro.io/) доступна функция **Factory Reset**, которая также стирает сохранённые пары.

⚠️ **Важно:** оба способа сбрасывают **все** сохранённые пары контроллеров сразу — точечного удаления одного конкретного устройства из списка BlueRetro не предусмотрено.

### 2.3. Сводная таблица по кнопке BOOT/IO0

| Действие | Длительность нажатия | Результат |
|---|---|---|
| Обычный сброс | < 3 сек | Reset системы |
| Вход в режим пейринга | 3–6 сек (LED мигает медленно) | Запуск inquiry mode |
| Сброс конфигурации + очистка ключей пейринга | 6–10 сек (LED мигает быстро) | Configuration reset + unpair всех устройств |
| Factory reset ESP32 | > 30 сек | Полный сброс прошивки и настроек |
| Короткое нажатие в режиме пейринга | — | Остановить пейринг / отключить все BT-устройства |

## 3. Совместимость геймпадов

Проверено на прошивке `v25.04 hw1 nes`.

| Геймпад | Протокол | Результат |
|---|---|---|
| Xbox One (модель 1708 и новее, с кнопкой Sync) | Classic BT | Работает (подтверждено) — см. раздел 1 |
| No-name GamePadPlus V3 (AliExpress), режим **X + Home** | BLE | Работает (подтверждено) |
| No-name GamePadPlus V3, остальные режимы (A / B / Y + Home) | BLE / Classic BT | Подключается, но кнопки не передаются (подтверждено) |

### 3.1. No-name геймпад GamePadPlus V3

Геймпад имеет четыре режима подключения, которые выбираются комбинацией кнопок при включении. С BlueRetro работает **только режим X + Home**.

**Подключение (первый раз):**

1. Убедиться, что BlueRetro в режиме поиска (пульсируют IO17 и LED свободного порта — см. раздел 1).
2. На **выключенном** геймпаде зажать кнопку **X** и, не отпуская её, нажать **Home** (центральная кнопка).
3. Геймпад сопрягается с BlueRetro: глобальный LED (IO17) гаснет, LED порта переходит в постоянное свечение.

**Повторные подключения:** геймпад запоминает последний выбранный режим — достаточно нажать **Home** (подтверждено).

**Если геймпад подключился, но кнопки не работают** (LED порта горит постоянно, но на линии DATA нет сигнала): геймпад включён в другом режиме — чаще всего в заводском A + Home. Выключить геймпад и включить заново комбинацией **X + Home**.

Каждый режим виден BlueRetro как отдельное устройство (со своим Bluetooth-адресом), поэтому после смены режима геймпад сопрягается заново и занимает отдельный ключ пейринга.

**Режимы геймпада и причины несовместимости** (по логу ESP32, см. раздел 4):

| Комбинация | Протокол | Выдаёт себя за (VID:PID) | Результат с BlueRetro |
|---|---|---|---|
| A + Home (заводской) | BLE | `1949:0402` | HID-дескриптор не разбирается (`Unknown HID marker: 36`) — нет данных |
| B + Home | Classic BT | Sony DualShock 4 `054C:09CC` | Включается драйвер PlayStation, клон не отвечает как настоящий DS4 — нет данных |
| **X + Home** | BLE | `5803:BDF8` (обычный HID-геймпад) | **Работает** |
| Y + Home | BLE | `1603:FCF1` (HID-мышь) | Режим мыши: стиков и кнопок геймпада нет — к NES неприменим |

**Признак рабочего режима в логе:** после подключения появляется строка раскладки входного отчёта, например:

```
4 I 0130 0 8 0131 8 8 0132 16 8 0135 24 8 0139 32 4 0901 40 16 02C4 56 8 02C5 64 8 rtype: 2
```

Если вместо неё стоит `Unknown HID marker` или строка содержит только кнопки и оси X/Y мыши — режим не подходит.

## 4. Получение лога подключения с ESP32

Лог BlueRetro в последовательном порту показывает, как геймпад подключается и распознаётся. По нему можно понять, почему подключённый геймпад не передаёт кнопки (см. раздел 3.1).

1. **Подключиться к Serial Terminal.** Подключить ESP32 к компьютеру по USB и открыть порт в SecureCRT или через `pio device monitor`. Параметры подключения (порт, скорость, настройки SecureCRT) приведены в разделе «Прошивка firmware → Serial Monitor Debug» документа `blueretro-murmulator-project-summary.md`.
2. **Перезапустить ESP32** кнопкой RESET (SW2), чтобы лог начался с момента старта.
3. **Подключить геймпад** — включить его и при необходимости выполнить пейринг (раздел 1 или 3.1).
4. **Смотреть лог в окне терминала.** Подключение, разбор геймпада и отключение выводятся построчно. Чтобы сохранить лог для анализа, скопировать вывод терминала в текстовый файл.

⚠️ Нечитаемые символы в начале вывода, сразу после старта (пока инициализируется Bluetooth-радио), — нормальное поведение, а не ошибка прошивки.

**На что смотреть в логе:**

| Строка в логе | Значение |
|---|---|
| `LE ADV ... bdaddr: ...` | Геймпад подключается по BLE |
| `Page ...` / `Inquiry ... bdaddr: ...` | Геймпад подключается по Classic BT |
| `dev: 0 type: ... <имя>` | Имя, которое сообщает геймпад |
| `VID: 0x.... PID: 0x....` | Идентификатор, под который маскируется геймпад |
| `1 I 0130 0 16 0131 16 16 ...` | Раскладка входного отчёта построена — кнопки будут передаваться |
| `Unknown HID marker: ..` | BlueRetro не смог разобрать описание геймпада — кнопки передаваться не будут |
| `DISCONN from dev: 0` | Геймпад отключился |
